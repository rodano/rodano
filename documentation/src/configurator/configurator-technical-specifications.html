Introduction

The configurator is a Javascript application that allows to configure with ease all aspects of a clinical study built with Rodano. The configurator can run in two different modes:

  • Stand-alone, used to create a new study.
  • Hosted by a Rodano server, used to edit an existing configuration.

Functional requirements

Study

In stand-alone mode, the configurator offers to create a study from scratch.

Language

Add a language

It should be possible to add a language.

Process

The user moves his mouse over the "Language" entity in the nodes tree and click on the addition icon (green plus). The application then shows an edition panel and the user updates language settings.

Pre-conditions
  • Id of the new language must not already exist in the configuration.
Post-conditions
  • A new language is added in the configuration (FS_LANGUAGE_001).

Edit a language

It should be possible to edit a language.

Process

The user selects a language in the nodes tree. The application shows an edition panel and the user updates language settings.

Pre-conditions
  • The new language id must not already exist in the configuration.
Post-conditions
  • Language settings have been updated (FS_LANGUAGE_002).

Delete a language

It should be possible to delete a language.

Process

The user moves his mouse over the language on the node tree and click on the deletion icon (red cross).

Pre-conditions
Post-conditions
  • The language has been deleted (FS_LANGUAGE_003).
