Introduction

Node templates are configuration elements (for example field models, workflows or entire studies) that are saved in a repository on a server so that they can be reused.

Node templates types

The following entities can be saved as templates:

  • Study
  • Sheet (a combination of a dataset model and a page)
  • Dataset model
  • Field model
  • Workflow

Node templates server

All templates are stored as files on a server. The server provides an API to add or delete templates. This API is written in JavaScript and run with Node.js.

Source code

The source code of the server is hosted in the same repository as the Configurator application. It consists of a single JavaScript file.

Server setup

The template server requires a working Unix OS with Node.js and a Node.js script called "forever".

The command to start the server is:

forever start template.server.node.js

Node templates management in the Configurator

The Configurator is used to manage node templates. It can create templates from configuration nodes and save them in a repository.

The Configurator can be set up to work with multiple template repositories.

Repositories configuration

Local repository

By default, the Configurator comes with a pre-configured local template repository. It stores templates locally, directly inside the browser, and behaves exactly like the official Rodano template server.

However, by design, this repository cannot be used to share templates across the company because it is not shared between Configurator users.

Configure the official Rodano repository

The first thing to do is to configure the official Rodano template repository.

  • Use the menu Tools>Templates.
  • Click "Manage repositories" in the upper right corner of the templates window.
  • Click "Add repository".
  • Set "rodano" for the id, "http://templates.rodanotech.ch" for the URL, "rodano" for the login and the usual password for the password.
  • Click "Test" to check that everything is correct.
  • Click "Submit" to save the configuration.
  • Close the window.

In the title of the templates window, it is now possible to switch to the newly created "rodano" repository. Existing templates should appear, sorted into different sections.

Node template creation

Go to the node you would like to save as a template. If it is a supported entity, a disk icon is shown in the title of the node form.

After clicking this icon, you must set a name and a description for the template. You should also check that the selected repository is "rodano".

Limitations

Not all node information is saved in the template. The limitations are described below.

Field model

All references to validators are removed. All initialization rules and modification rules are removed.

Dataset model

All field models are cleaned as described above.

Workflow

All workflow rules and rules on workflow actions are removed.

Sheet

Sheet templates are specific in that they are a combination of a form model, the dataset model and the field models used in the form model. It is not possible to create a sheet template from a page that is linked to more than one document.

Restrictions for the Configurator

When creating a template for the Configurator, there are also specific restrictions.

Study
  • the study must contain scope models with the ids "STUDY", "COUNTRY", "CENTER" and "PATIENT";
  • the study must have a single scheduled event group whose id is "SCHEDULING";
  • if there is a baseline event model, its id must be "BASELINE" and it must be inside the scheduled event group;
  • if there is a screening event model, its id must be "SCREENING" and it must be inside the scheduled event group;
  • the validators "REQUIRED" and "REQUIRED_WITH_QUERY" must exist;
  • the profiles "INVESTIGATOR", "DATAMANAGER", "CRA", "CRO" and "SPONSOR" must exist;
  • the workflows "QUERY" and "PROTOCOL_DEVIATION" must exist;
  • the workflows "EVENT_SDV" and "PAGE_SDV" must exist;
  • the workflows "PAGE_ENTRY", "DATA_MANAGEMENT" and "EVENTS_REPORTING" must exist.

Node template usage

Node templates that are not studies can be added to any existing configuration.

While editing an existing configuration, use the menu Tools>Templates to open the template management modal window. After selecting the right kind of template in the section on the left, click the plus icon to add the selected template to the current configuration.

Node template deletion

While editing an existing configuration, use the menu Tools>Templates to open the template management modal window. After selecting the right kind of template in the section on the left, click the red cross to delete the selected template.

Node template modifications

The process to edit a node template depends on the kind of template.

Templates that are not studies

There is no way to edit these kinds of templates. They must be deleted and re-created.

Study templates

Study templates can be edited in the Configurator. In stand-alone mode, use the welcome modal window to load a study from a configured template repository.

It is then possible to push a template to the template server using the menu Configuration>Push template to server.

Templates usage in the Configurator

The Configurator is pre-configured to show study, page and attribute templates from the official Rodano repository. Every user of the Configurator has access to the templates stored on this server.
